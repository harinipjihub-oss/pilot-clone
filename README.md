# Pilot UI Clone

A local React + Vite reproduction of the four Pilot screens supplied as reference screenshots:

- Home: `/home`
- Dashboard: `/dashboard`
- My Tasks: `/tasks`
- My Works: `/my-works`

This is a frontend clone using static/mock data. It does not connect to the original Pilot backend, database, authentication, or APIs.

## Run in VS Code

Requirements: Node.js 20.19+ (or a compatible current Node release supported by Vite).

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite. Vite's current documentation uses `npm create vite@latest` and `npm run dev` for this workflow.

## Build

```bash
npm run build
npm run preview
```
